# 💧 هروب القوارير — لعبة مطاردة 3D أوفلاين

لعبة مطاردة وهروب ثلاثية الأبعاد من منظور الشخص الثالث. تتحكم بشاب عربي خيالي يحمل حقيبة قوارير ماء،
ويحاول الهروب من مطاردين (شخصيات خيالية بالزي الإماراتي التقليدي) والوصول إلى نقطة الهروب قبل انتهاء الوقت.

- **أوفلاين بالكامل**: بدون خادم، بدون تسجيل دخول، بدون حساب، بدون إنترنت.
- **التقدم يُحفظ محليًا** على الجهاز (`localStorage`).
- كل الرسومات والقوام والأصوات والموسيقى **مولّدة برمجيًا** — لا توجد ملفات خارجية.

## التشغيل

**أسهل طريقة:** افتح الملف `dist/index.html` مباشرة في المتصفح (Chrome / Edge / Safari / Firefox) على الكمبيوتر أو الجوال.
الملف واحد ويحتوي كل شيء.

للتطوير:

```bash
cd game
npm install
npm run dev      # خادم تطوير محلي
npm run build    # يُنتج dist/index.html (ملف واحد يعمل أوفلاين)
```

عند تشغيله عبر خادم (http/https) يمكن "تثبيته" كتطبيق على الجوال (PWA) ويعمل بدون إنترنت بعد أول فتح.

## أسلوب اللعب

- **الجري يستهلك الطاقة** (الشريط الأصفر). المطاردون في المراحل المتقدمة أسرع من مشيك — استخدم الجري بذكاء.
- **القوارير**: إصابة المطارد تبطئه وتربكه لثوانٍ، والماء المنسكب يترك بقعة تبطئ من يمر فوقها. القوارير محدودة؛
  التقط المزيد من صناديق القوارير الزرقاء المتوهجة (تعود بعد 25 ثانية).
- **الحواجز الخرسانية** يمكنك القفز فوقها، أما المطاردون فيلتفون حولها.
- **السيارات والأسوار** تحجب الرؤية — اختبئ خلفها ليفقدك المطاردون.
- السهم الأخضر أعلى الشاشة والخريطة المصغّرة يدلانك على نقطة الهروب.
- النجوم: ⭐ للفوز، ⭐ إذا بقي أكثر من 35% من الوقت، ⭐ إذا بقيت صحتك فوق 60%.

## الذكاء الاصطناعي للمطاردين

آلة حالات لكل مطارد (`src/ai/ChaserAI.js`):

1. **دورية/بحث** (`patrol`): يتجول بين نقاط في المدينة.
2. **اكتشاف**: مخروط رؤية بمدى وزاوية محددين + خط رؤية حقيقي (السيارات والمباني تحجب)، وسماع الخطوات القريبة (الجري أعلى صوتًا).
3. **رد فعل** (`alert`): يلتفت ويتوقف لحظة قبل الانطلاق (أقصر في المراحل المتقدمة).
4. **مطاردة** (`chase`): مسار A* على شبكة ملاحة، مع توقع حركة اللاعب.
5. **قطع الطريق** (`intercept`): بعض المطاردين يتجهون لنقطة بين اللاعب وأقرب مخرج. ومن المرحلة 3 يوجد **حارس** للمخرج (`guard`).
6. **هجوم قريب** (`attack`): اندفاعة قصيرة ثم ضربة تُنقص الصحة وتدفع اللاعب.
7. **فقدان اللاعب**: إذا اختفى عن النظر لفترة (الذاكرة) أو ابتعد كثيرًا.
8. **العودة للبحث** (`search`): يتفقد آخر موقع معروف وما حوله، ثم يعود للدورية.

الفريق يتشارك آخر موقع معروف للاعب، ومدى التنبيه يزداد مع المراحل. كل المعاملات تُشتق من قيمة `ai` (0..1) في `src/config/levels.js`.

## بنية الكود

```
src/
  main.js                 نقطة الدخول وربط الأنظمة
  config/levels.js        إعدادات المراحل ومعاملات الذكاء الاصطناعي
  core/
    Game.js               المنسّق: تحميل المرحلة، الحلقة، الحالات، الفوز/الخسارة
    Renderer.js           العارض، الجودة، الإضاءة، السماء، الدقة الديناميكية
    Collision.js          فيزياء الشخصيات والتصادم (AABB) + Raycast + خط الرؤية
    Input.js              لوحة المفاتيح والفأرة واللمس
    Random.js             أرقام عشوائية ثابتة البذرة
  world/
    MapBuilder.js         توليد المدينة الخليجية (مبانٍ، طرق، سيارات، حواجز، مخارج)
    Props.js              نماذج السيارات والنخيل والحواجز والإنارة...
    Textures.js           قوام مولّدة عبر Canvas
    Geometry.js           دمج الأجسام الثابتة لتقليل draw calls
  entities/
    Player.js             حركة اللاعب، الجري والطاقة، القفز، الرمي
    Chaser.js             جسم المطارد واتباع المسار
    CharacterModel.js     نماذج الشخصيات والتحريك الإجرائي
  ai/
    ChaserAI.js           آلة حالات الذكاء الاصطناعي + ذاكرة الفريق
    NavGrid.js            شبكة الملاحة وبحث A*
  weapons/BottleSystem.js رمي القوارير بالفيزياء والإصابة
  systems/
    Health.js             نظام الصحة
    Particles.js          رذاذ الماء وبقع الماء
    Pickups.js            صناديق القوارير الإضافية
  camera/ThirdPersonCamera.js  كاميرا ناعمة مع منع اختراق الجدران
  audio/
    AudioManager.js       المؤثرات الصوتية (Web Audio)
    Music.js              موسيقى إجرائية بمقام الحجاز وإيقاع المقسوم
  ui/
    HUD.js, Menus.js, TouchControls.js
  save/SaveSystem.js      حفظ التقدم والإعدادات محليًا
```

## الأداء

- دمج الأجسام الثابتة حسب المادة وتقسيمها لقطع تسمح بالاستبعاد خارج مجال الرؤية.
- ظل واحد يتبع اللاعب بدقة تختلف حسب الجودة.
- ثلاث مستويات جودة + وضع تلقائي يخفض الدقة إذا انخفض معدل الإطارات.
- منطق اللعبة (AI + فيزياء) يستغرق أقل من 1–2 ملي ثانية للإطار في أصعب مرحلة.
